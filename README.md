# YouTube VOT — Android

Нативный модуль закадрового перевода для YouTube 20.14.43: кнопки перевода и настроек в плеере, обычные/живые голоса, языки, раздельная громкость, субтитры и загрузка готовой озвучки. Исходный плеер сохраняется; отдельный MediaPlayer воспроизводит перевод, синхронизируясь с его временем и состоянием.

Панель повторяет [iPhone-версию](https://github.com/AurelVU/youtube-vot-ios): текстовая кнопка перевода слева сверху, рядом круглая кнопка «⋯», тёмные сгруппированные настройки. Окно входа Яндекса поддерживает экранную клавиатуру. Проверялось на Samsung Galaxy Tab S7+ с Android 13.

Это независимый экспериментальный проект. Он не связан с Google, Яндексом или ReVanced. Неофициальный API и внутренние методы приложения могут измениться. Поддерживаются обычные ролики до четырёх часов; Shorts и дистанционное воспроизведение не входят в проверенный сценарий. Для живых голосов может требоваться вход в Яндекс через настройки модуля.

## Сборка

Требуются JDK 17, Android SDK 36 / build-tools 36.0.0, Python 3, bash и curl. Исходные APK и средства подписи не входят в репозиторий. `build/`, `vendor/` и ключи исключены из Git.

Для текущей сборки используются официальные ReVanced CLI 6.0.0 и patches 6.2.1. Исходники upstream находятся в `vendor/patches` для справки, полный upstream Gradle не требуется: Java-патч компилируется против официальных JVM API, затем добавляется в отдельную копию RVP вместе с собственным DEX. Оригинальный RVP не изменяется.

```sh
bash scripts/build.sh
```

Скрипт выполняет автономные проверки протокола, изоляции запросов, отмены, HTTP-парсера, субтитров, часов синхронизации, индикатора готовности и восстановления громкости. Затем компилирует Android-код и отдельный патч. Compile-only stubs и имитаторы Android для тестов в DEX не включаются. Проверяется не только обнаружение патча, но и фактическая загрузка и объединение extension через отдельный classloader.

Нужны локальные `build/revanced-cli.jar` и `build/patches.rvp`, а для финальной упаковки — совместимый оригинальный APK. Сборка библиотеки не означает проверки звука на устройстве.

## Источники сборки

- Менеджер: официальный [ReVanced Manager 2.6.0](https://github.com/ReVanced/revanced-manager/releases/tag/v2.6.0); его SHA-256 сверяется с релизом.
- Метаданные менеджера: `https://api.revanced.app/v5/patches` и `https://api.revanced.app/v5/manager/downloaders`.
- Совместимость определяется `revanced-cli list-versions -p build/patches.rvp -b -f com.google.android.youtube -u`. Версия 20.14.43 имеет такую же максимальную совместимость с текущим RVP, как несколько более новых поддерживаемых версий.
- Для подготовки нужна совместимая оригинальная версия YouTube 20.14.43, полученная с необходимыми правами. Исходный APK и способы снятия DRM этот репозиторий не предоставляет.
- Объединение split APK: официальный [REAndroid APKEditor 1.4.9](https://github.com/REAndroid/APKEditor/releases/tag/V1.4.9), библиотека этого проекта также используется загрузчиком ReVanced Manager.
- Для ресурсов используется AAPT2, поставляемый с ReVanced CLI: обычный SDK AAPT2 отвергает некоторые исходные имена ресурсов YouTube с `$$`.

Патч `Voice-over translation` выключен по умолчанию. Для финальной локальной сборки он явно включается вместе с `GmsCore support`, `Spoof video streams` и `Custom branding`; имя приложения — `YouTube VOT`. Пакет `app.revanced.android.youtube` устанавливается отдельно от штатного `com.google.android.youtube`. Для него нужен официальный ReVanced GmsCore; вход в Google не выполняется автоматически.

После сборки модуля: `bash scripts/build-apk.sh`. Скрипт использует постоянный локальный `signing/youtube-vot.keystore`, чтобы обновления устанавливались поверх предыдущей версии. Этот файл исключён из Git; сохраните его для дальнейших обновлений. Параметр имени приложения в CLI — `-O 'App name=YouTube VOT'`.

## Данные

Авторизация Яндекса хранится только в WebView и памяти процесса. Cookie добавляется только к прямому HTTPS-запросу перевода на `api.browser.yandex.ru`; не передаётся worker-серверу, медиа или субтитрам. Запросы используют отдельный TLS-транспорт с проверкой цепочки и имени сервера, без общего CookieHandler и автоматических редиректов.

Неавторизованный запрос при ошибке может перейти на сторонний `vot-worker.toil.cc`; этот сервер получает ссылку и параметры видео. API/медиа-серверы видят обычные сетевые сведения, например IP. Логи не содержат cookie или произвольных тел ответа. Перевод не является локальной обработкой.
